## Overview

Global Supreme Ministries is the official website for a Christian non-profit, providing a public presence alongside authenticated member features and content management for the ministry's teaching materials.

## Features

- **Member Authentication**: Sign-up and login for church members.
- **Content Management**: Manage sermons, books, and devotionals from an admin interface.
- **Events Gallery**: Showcase photos and details from ministry events.
- **Public Membership Sign-Up**: Lets visitors join as members directly from the site.

## Technologies Used

- **NuxtJs**: The Intuitive Vue Framework.
- **VueJs**: The Progressive JavaScript Framework.
- **TypeScript**: Typed JavaScript at Any Scale.
- **Drizzle**: A type-safe, lightweight TypeScript ORM.
- **Postgres**: The World's Most Advanced Open Source Relational Database.
