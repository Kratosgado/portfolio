## Overview

Autoscroll Chrome Extension automatically scrolls the current page at a speed you control, useful for reading long articles or documents hands-free.

## Features

- **Automatic Scrolling**: Continuously scrolls the page without manual input.
- **Adjustable Speed**: Control scroll speed from the extension toolbar.
- **Toggle On/Off**: Quickly enable or disable scrolling per page.

## Technologies Used

- **JavaScript**: Core extension logic.
- **Chrome Extension**: Built on the Chrome Extensions API.
